# robot-basic

Arduino and OpenMV code for a mobile robot system with visual sensing, line following, object recognition, and motion control.

## Contents

- `arduino/`: Arduino control programs
- `openmv/`: OpenMV vision program
- `media/`: project demonstration videos
- `docs/`: project documentation

## Demonstrations

- `media/demo-short.mp4`: short project demonstration
- `media/demo-full.mp4`: approximately five-minute project demonstration, compressed for repository hosting
